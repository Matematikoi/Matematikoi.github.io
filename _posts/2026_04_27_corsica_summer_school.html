Data reduction:

Given a dataset D A set of contraints C

What to retain/dispose how much to retain/dispose when to retain/dispose

Identify D' with D' subset of D. Such that D' staisfies C and maximises some utility function.

Some terms:

  • Data rotting
  • data amnesia
  • data reduction

methods

Selective storage

  • statistical summarization

    For example statistical methods: mean, std, etc..

    Distributions like histograms.

  • Sketches

    compact data summaries or probabilistic data structures for efficient computation.

    Give up some accuracy for significant efficiency.

    1. count-min sketch
    2. hyperlog
  • Coreset-selection

    A smaller subset that for a given function it approximates the function on the full dataset.

  • Wavelet (lossy disposal)

    representation in compact hierarchical maner.

  • View maintenance

Compression

you take another representation of the same dataset. The end goal is to be able to recover the data, not throw it away.

  • Syntactic
    • Patern-based

      instead of storing a pattern you store a representation for the pattern itself

      For example:

      1. Huffman encoding.
    • Dimensionality reduction

      represent as a good set of some linear representation.

  • Semantic compression

remove redundancy

  • Schema deduplication
  • instance deduplication

    identifying that two different structures in the same database correspond to the same data point.

deletion
